# Contributing

This is a personal site, so its direction and content are not open to
contribution, but bug reports and small fixes are welcome:

- **Typos and broken links**: open a PR directly, no issue needed.
- **Bugs** (layout breakage, accessibility problems, build issues):
  open an issue with your browser/viewport, or a PR if the fix is
  small and self-contained.
- **Features and design changes**: please don't; the site is its own
  design exercise. Forks are of course welcome under the license.

Before a PR: `bun test && bun run check && bun run build` should all
pass.
