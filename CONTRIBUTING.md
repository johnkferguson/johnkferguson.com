# Contributing

As this repo is my personal blog, there shouldn't be much need for contributors.

However, I'm still open to contributions in any of the following areas:

- If any of the logic for the mechanisms I design are incorrect, go ahead and open an issue or PR.
- Same if there's anything broken directly in the site: layout problems, accessibility issues, issues during load, etc., go ahead and open an issue or PR.
- Typos, broken links and other minor things: a PR is good.
- If there's something that would improve performance or if there's a better way of doing something without changing behavior, go ahead and open a PR. If it's good I'll merge it.

For things like features, design changes, etc., I'm not seeking anything. But if you have something you think would be worthwhile you can open an issue or PR, but know that there's a good chance I won't implement it.

For PRs:

- Write commit messages in conventional commit style.
- Run `bun test && bun run check && bunx astro check` locally first to ensure everything passes.
